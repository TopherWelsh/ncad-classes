# Track Critique Rubric

Built in Week 2; used every week after. A rubric turns your brief into a critique tool — for judging AI output, your own drafts, and peers' work with the same standard.

**How to build yours:** take your creative brief's constraints and goal, and convert each into a question a draft can pass or fail. No generic art-school questions — every line must reference *your* brief.

---

## Project: ____________________  Track: ____________________

### The five course questions (always included)

1. Where is the human point of view in this?
2. What did the model (or habit) make generic — and did I catch it?
3. What did I reject, and why?
4. What would make this portfolio-safe (craft + disclosure)?
5. What would I verify before showing a client?

### Worked examples by track

- **Motion:** "Does the first 2 seconds earn the next 13?" / "Does type remain readable at story-size on a phone?"
- **Illustration:** "Does the silhouette read at thumbnail size?" / "Is the costume detail consistent with the character bible?"
- **UX:** "Can the unhappy path recover without a dead end?" / "Does every status use more than colour alone?"
- **Graphic design:** "Does hierarchy survive at 5 metres AND at phone size?" / "Could this be any college's poster?" (generic test)
- **3D:** "Will this topology deform cleanly?" / "Is every light motivated?"
- **Video:** "Do the captions survive the fastest cut?" / "Is anything on screen unverified?"

### Using it with AI

Paste the rubric after any output:
> Judge the above against this rubric, line by line. Pass/fail each, one sentence of evidence. Then revise only the failing items.
