Part 1, continued

Code as dictation

~0:18. The week's superpower.

The loop

Four steps

  1. Describe the setup in artist language
  2. Demand artist comments — "for an artist who doesn't code"
  3. Paste → Scripting tab → Run
  4. Change values → re-run
That's the entire method. The demo proves it in 40 minutes.

The mindset

A script is a dial, not a black box

Rock count. Fog density. Light warmth.
Numbers, in plain view, that you're allowed to change.

The first time you edit a value and re-run, you have technically edited Python.

"Nobody will check your licence."

When it breaks

The error loop

I ran your script in Blender 4.x and got this error: [paste the ENTIRE traceback]. Explain in plain language and fix it.

You don't debug. You report.

"Like describing a render glitch to support — except the support answers. Usually first try."

Absolute

Safety rules

  1. Fresh or saved files only. Never your only copy.
  2. Read for destructive operations — delete, remove, file paths → ask first.
  3. Undo exists. Rule 1 anyway.
Deliver flatly. These return in Week 12 as agent rules.

The professional eye

The Reality Check — 10 seconds, forever

Wireframe view → density? · loops where it bends? · backside? · ngons? · scale?

→ Verdict: background / blocking / retopo (cost it) / reject

Runs in the lab on a provided mesh. Studios literally pay for this judgment now.

Demo · move 1

The ask

Write a Blender 4.x Python script that builds a previz scene: ground plane with subtle displacement, 12 low-poly rocks scattered without overlaps, three-point area lighting, camera framing the cluster from low angle, light volumetric fog. Comment every section in plain language for an artist who doesn't code. List what could go wrong when I run it.
Read the comments aloud when it returns. Read its own risk list.
Demo · move 2

The run

Scripting tab → paste → Run → orbit

One paste. That used to be forty minutes of setup.

Let the scene land. Orbit slowly.
Demo · move 3

The dials

Rocks: 12 → 40. Fog: doubled. Re-run.

A script is a dial, not a black box.

Invite a student to call a value. Change it live.
Demo · move 4

The planned crash

It failed. Good.

Read the traceback. Copy ALL of it. Paste it back.

"You don't need Python. You need copy-paste and honesty about what happened."

Let the error be scary for two seconds, then run the loop. Fix usually lands first try.
