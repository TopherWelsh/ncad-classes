02Key Concepts

1 · The 3D AI map (honestly rated)

CapabilityStateUseful for
AI-written scripts (Blender Python)★★★Scene scaffolds, repetitive setup, batch ops — today's core

Texture/material generation★★Tileables and roughs; PBR correctness needs your eye

2 · Code as dictation

  1. Describe the setup in artist language ("ground plane with subtle displacement, 12 scattered low-poly rocks, three-point lighting, camera low, light fog").
  2. Demand artist comments — "comment every section in plain language for an artist who doesn't code."
  3. Paste → Scripting tab → Run.
  4. Change values, re-run. A script is a dial, not a black box — the first time you edit a value, you've edited Python.

3 · The error loop: errors are conversation

Copy the entire traceback → paste it back → "I ran your script in Blender 4.x and got this error; explain in plain language and fix it." It fixes itself, usually first try. You don't debug; you report.

Safety rules — absolute
  • Fresh or saved files only. Never your only copy of a project.
  • Read scripts for destructive operations first — delete, remove, file paths get a question before running.

4 · The topology tax

AI mesh generators produce shapes that look right and are built wrong: triangle soup, no edge flow, ngons, melted backsides, absurd scale. "Free model" = "paid in cleanup." Legitimate uses anyway: background props, blocking volumes, scale reference — never hero assets, never anything that deforms.

In real work

The professional eye — wireframe view, ten seconds, verdict — is exactly the evaluation labour studios now pay for. Today's Reality Check trains it.

5 · Scene plans and render QA

Before: the scene plan — frame contents, asset list with sources, every light with a stated motivation, camera intent, honest render budget. After: the render checklist (previz vs. final) and symptom-based triage ("grainy shadows, Cycles, 40-minute frames" → diagnostic order).

04Demo: The Scene Scaffold (and the Planned Crash)

I made this, so can you

A dressed, lit, camera-ready previz scene from one paste — then a crash, repaired by copy-pasting the error.

Prepared demo artifact

Instructor backup / finished example: scene_scaffold.py scene_scaffold_broken.py. Use it if the live tool run fails, or to reveal the finished structure after critique.

  1. The ask: plain-language scene description → Blender 4.x Python with artist comments → "list what could go wrong."
  2. The run: Scripting tab → paste → Run → orbit. One paste; forty minutes of setup, gone.
  3. The dials: rock count and fog density changed live, re-run. A script is a dial, not a black box.
  4. The planned crash: a version-mismatched script fails; the full traceback goes back to the model; the fix lands. "You don't need Python. You need copy-paste and honesty about what happened."
  5. The artist's judgment: what no script provides — composition intent, story, materials with meaning, light motivation. Then the render checklist, previz vs. portfolio still.

05Step-by-Step Workflows

A script request that works first time (more often)

  1. Name your version: "Blender 4.x Python."
  2. Describe like a brief: objects + counts, placement logic, lighting (count, type, feel), camera (angle, subject).
  3. Demand artist comments on every section.
  4. Ask for the risk list: "what could go wrong when I run this?"
  5. Run in a fresh/saved file — after reading for destructive operations.
  6. Iterate by value, then by feature.

The Topology Reality Check (10 seconds per asset, forever)

  • Import → wireframe view.
  • Density: consistent, or soup with absurd concentrations?
  • Edge flow: loops where the form bends/deforms?
  • The backside: intact, or melted?
  • Ngons / non-manifold: check Mesh → Clean Up, or just look.
  • Scale + origin: sane?
  • Verdict: background / blocking / retopo (cost it honestly) / reject.

06Prompt Recipes

The scene scaffoldWrite a Blender 4.x Python script that builds a previz scene: [describe like a brief — objects + counts, placement logic, lighting (count, type, feel), camera (angle, subject), atmosphere]. Comment every section in plain language for an artist who doesn't code. At the end, list what could go wrong when I run it.
The error loopI ran your script in Blender [version] and got this error: [paste the ENTIRE traceback]. Explain what went wrong in plain language, then provide the fixed script.
The repetitive-task killerWrite a Blender 4.x Python script that [the boring thing — renames all selected objects to the pattern PROJ_type_## / sets all selected materials' roughness to 0.4 / creates collections named X,Y,Z and sorts selected objects into them by name]. Plain-language comments. Nothing destructive: don't delete anything; if unsure, skip and report.
The scene planI'm building a 3D scene: [concept + what it's for]. Draft my scene plan: everything in frame, asset list with source column (model / buy / scan / AI-mesh-for-background), lighting plan where every light has a stated motivation, camera intent, and an honest render budget (previz vs final). Flag the two assets that will eat the most time.
The render triageMy render problem: [symptoms — grainy shadows / fireflies / 40-min frames / blotchy denoising]. Engine: [Cycles/Eevee], hardware: [GPU/CPU, RAM]. Diagnose the likely causes in order of probability and give me the settings to try, with what each trades away.
The material describerDescribe a Blender shader node setup for [material — e.g., sea-worn painted steel, flaking, slightly oily]: nodes, key values, and what to photograph for reference. I'll build it by hand — give me the recipe, not a script.

07Lab: Topology Reality Check + Your Scaffold (70 min)

Cold start friendly. No Blender on your laptop? Pair up, or take the planning track — fully equal.

  1. Run the class scaffold (15 min): paste the provided script → run → change two values → re-run. You've now edited Python.
  2. Your scaffold (20 min): request one for your project — Week 6 character's set, degree-show space, product turntable. Hit an error? Error loop — that's the skill, not a failure.
  3. Reality Check (15 min): wireframe pass on the provided AI mesh → 5 written findings + a verdict.
  4. Scene plan + keeper (20 min): plan for your real project + ONE script/checklist you'll actually reuse. Save the prompt with the script.
Planning track (no Blender needed)

Scene plan document (frame contents, asset sources, light motivations, camera intent, budget) + a written script spec + Reality Check on the provided annotated screenshots. The director's version of the same knowledge — equal credit.

08Integrity Check

This week's four
  1. Did you read your script for destructive operations before running it?
  2. AI meshes in your scene: would you disclose them in a portfolio breakdown? ("Background rocks AI-generated, cleaned; hero asset modelled by me" is exactly how studios talk.)
  3. Can you state why each light exists — or did the script decide your look?
  4. A script in your pipeline is a dependency: save the prompt with the script so future-you can regenerate it.
