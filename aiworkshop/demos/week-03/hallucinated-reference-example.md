# Hallucinated Reference Example

Use this when the live model happens to give all real references.

**Prompt context:** "near-future tech unease for a Dublin music venue, avoiding neon-rain cliches."

**Confident model output to challenge:**
> Contemporary reference: "Niamh O'Shea's 2021 exhibition *Signal Rot* at Project Arts Centre, which used thermal camera distortions and emergency-broadcast typography."

**Verification result:** no reliable evidence found for this exhibition/title pairing.

**Teaching point:** the phrasing sounds exactly like an arts listing. That is the danger. The fix is not "never use references"; the fix is verify every named reference before it enters the moodboard, handout, or critique conversation.
