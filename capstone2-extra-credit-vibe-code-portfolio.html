Vibe Code Your Portfolio Website

Use Claude Code or ChatGPT Codex to build a custom portfolio website from a folder of your own work, then deploy it with free hosting.

Claude Code ChatGPT Codex Cloudflare Pages Back to Capstone 2

The Challenge

Create a custom motion design portfolio website using a vibe coding workflow. You will organize your work into one project folder, use AI coding tools to design and build the site, then publish it online so you have a real portfolio link.

⚠ Do This On Your Own Computer

This assignment should not be built on school computers. You need your own project folder, your own login accounts, and control over the files, permissions, domain, and hosting setup.

Recommended Tool Stack

AI Coding App

Use Claude Code or ChatGPT Codex. The lowest paid plan is enough for this assignment. The tool will help write, edit, organize, and troubleshoot your website files.

Free Hosting

Use Cloudflare Pages for free static website hosting. It is fast, professional, and works well for portfolio sites built from HTML/CSS/JS or simple frameworks.

Your Domain

Buy a domain name if you can. A custom domain makes the site feel more professional and gives you one clean link for reels, resumes, internships, clients, and applications.

Step 1: Make Your Root Folder

Everything Starts In One Folder

  • Create one root folder: Example: FirstnameLastname_PortfolioSite.
  • Keep it local: Put it somewhere you control, like Desktop, Documents, or an external drive.
  • Add your work: Motion design, animation, video, 3D, drawings, process images, storyboards, stills, PDFs, writing, and project notes.
  • Organize by project: Make folders like project-01, project-02, reel, process, and assets.
  • Use clear names: Avoid files named final_final_REAL2.mov. Rename things so the AI can understand them.
  • Export web versions: Use compressed MP4s, JPGs, PNGs, GIFs, or web-friendly assets.
  • Include text notes: Add short notes explaining each project, your role, tools used, and what the viewer should notice.
  • Back it up: Keep a copy of the folder before letting any AI tool make big changes.

Step 2: Assign The Folder To The AI App

Claude Code

  • Open Claude Code on your computer.
  • Open or attach your portfolio root folder as the working project.
  • When Claude asks for file permissions, allow access only to the portfolio folder you created.
  • Ask Claude to inspect the folder and summarize what assets it sees before it starts building.

ChatGPT Codex

  • Open Codex and start a coding session from your portfolio root folder.
  • Make sure the app is working inside that folder, not your whole computer.
  • Approve read/write actions only for website files and assets inside the project folder.
  • Ask Codex to list the folder structure first so you know it is looking in the right place.
🔒 Permission Rule

The AI should only need access to the portfolio folder. Do not give it random access to personal folders, passwords, private documents, client files, or anything unrelated to this site.

Step 3: Use The Word Vomit Technique

More Context Makes Better Results

Do not try to write a perfect prompt. Dictate or type pages of messy explanation: what you want the site to feel like, colors, type, layout, references, project order, page names, case study content, and what kind of motion designer you want to look like. The AI can parse typos, fragments, and your natural language. The more real material you give it, the more it can build from your taste instead of guessing.

Tell It The Vibe

Describe the personality: polished, experimental, cinematic, clean, brutalist, playful, technical, editorial, sleek, weird, soft, bold, minimal, maximal, or anything else that fits you.

Tell It The Design

Talk through colors, type styles, layout, navigation, spacing, motion, transitions, thumbnails, video presentation, and what you do not want it to look like.

Tell It The Content

Explain your projects, what files belong to each one, which pieces are strongest, what case studies need to say, and how your reel should be presented.

Starter Prompt

Paste This, Then Add Your Own Word Vomit

I am building a motion design portfolio website from this folder. First inspect the folder and summarize the assets you see. Then propose a site structure with a homepage, work/project gallery, demo reel area, about/contact, and case study pages for my strongest projects. Do not delete or overwrite my source assets. Ask before major changes. I want the site to feel like [describe your style]. My strongest projects are [list them]. My colors/type/layout references are [describe them]. I want the site hosted on Cloudflare Pages. Build a simple static site I can deploy.

Step 4: Build The Site In Passes

Recommended Build Order

  • Ask for a folder audit and site plan.
  • Approve the page structure before coding.
  • Build the homepage and navigation first.
  • Add project gallery and demo reel section.
  • Add case study pages with process images.
  • Test mobile layout and video playback.

Do Not Let It Drift

  • Stop it if the design becomes generic.
  • Ask for revisions in plain language.
  • Tell it when spacing, colors, type, or layout feel wrong.
  • Keep asking for stronger motion-designer presentation.
  • Review every page before deployment.
  • Keep backups before major rebuilds.

Step 5: Deploy With Cloudflare Pages

Free Hosting Path

  • Create a Cloudflare account: Use Cloudflare Pages for free static hosting.
  • Connect the project: The easiest route is usually pushing the site to GitHub, then connecting the repo to Cloudflare Pages.
  • Use a simple build: If it is plain HTML/CSS/JS, the output folder may simply be the root folder.
  • Preview first: Cloudflare gives you a preview URL before you attach a domain.
  • Buy or connect a domain: Purchase a domain and point it to Cloudflare.
  • Attach the custom domain: Add it inside the Cloudflare Pages project settings.
  • Check HTTPS: Make sure the secure version loads without browser warnings.
  • Test everything: Home, reel, project pages, videos, mobile layout, links, contact info.
🛠 Troubleshooting

If you get stuck, bring the problem to Topher. Be ready to show the folder, the AI conversation, the error message, the Cloudflare Pages screen, and what you already tried. The more specific the problem, the faster we can fix it.

What The Finished Site Needs

Identity

The homepage should clearly communicate who you are, what kind of motion/design work you make, and where your best work lives.

Work + Process

Project pages should show finished work and process: storyboards, styleframes, breakdowns, sketches, 3D tests, animation tests, or case study writing.

Function

The site should load, navigate, play media, work on mobile, and give viewers a clear way to contact you.

5 Point Scoring Guide

What Earns the Points

  • 1 point: Organized root folder with work/assets available to the AI tool.
  • 1 point: Custom site design that feels specific to the student, not a generic template.
  • 1 point: Portfolio includes reel/work gallery and at least one project/case study page.
  • 1 point: Site is deployed online with a working public link.
  • 1 point: Site functions properly: mobile, navigation, media, contact path, and no obvious broken placeholders.
