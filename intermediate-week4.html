RubberHose 3 Assignment

Create three short character animation studies using RubberHose 3: a walk cycle, an expressive action, and a styled hose showcase.

Discord Google Drive Hose Styling Docs

The Assignment

Design or adapt a simple character and produce three separate RubberHose 3 animation studies. Each study should demonstrate a different kind of character motion and a clear understanding of hose styling. The goal is not a full film; the goal is technical control, readable acting, and clean presentation.

🎨 What I Am Looking For

I want to see that you can build a usable limb rig, make intentional animation choices, and style the hoses so the character feels designed. Default rubber noodle limbs are not enough for this assignment.

Required Animation Studies

Study 1: Walk Cycle

Create a looping side-view walk cycle using RubberHose legs and arms.

  • Minimum 4 seconds
  • Must loop cleanly
  • Include contact, down, passing, and up poses
  • Show arm swing and leg motion
  • Character may walk in place or travel across frame

Study 2: Expressive Action

Create one short acting/action animation using RubberHose limbs.

  • Minimum 5 seconds
  • Examples: wave, jump, point, grab, throw, dance move, stretch, punch, stumble, celebrate
  • Must include anticipation and follow-through
  • Must use readable silhouette changes
  • Must feel different from the walk cycle

Study 3: Styled Hose Showcase

Create a short animation focused on hose styling and visual design.

  • Minimum 5 seconds
  • Use at least three styling methods
  • Examples: sleeve, cuff, outline, taper, trim path, dashed detail, glove/sock break, color bands
  • Show before/after or use labels so the styling choices are obvious
  • Keep the character moving, even subtly

Technical Requirements

Rig Requirements

  • Use RubberHose 3 for arms and/or legs in every study.
  • Controllers must be named and organized.
  • Hands, feet, shoes, gloves, or props must stay attached to the correct controller.
  • At least one animation must use parented hand/foot/prop artwork.
  • At least one animation must show clear overlap or offset timing.

Styling Requirements

  • Use at least three hose styling techniques across the project.
  • Use consistent color, outline, and limb thickness choices.
  • Use Trim Paths or multiple strokes for at least one clothing/detail effect.
  • Use a taper, dash, cuff, glove, sleeve, or outline treatment intentionally.
  • Default unstyled hoses should not be the final look.

Suggested Production Schedule

Class Block

  1. Choose or simplify your character.
  2. Separate artwork into rig-friendly layers.
  3. Build arms and legs with RubberHose.
  4. Style one limb system first, then copy/paste style to related limbs.
  5. Block the walk cycle before polishing.

Homework Block

  1. Finish walk cycle timing and loop.
  2. Create the expressive action study.
  3. Create the styled hose showcase.
  4. Add labels or quick title cards for each study.
  5. Render MP4 and collect/zipped AE project folder.

Walk Cycle Checklist

Minimum Walk Cycle Poses

  • Contact: Front foot lands, back foot pushes.
  • Down: Weight drops after contact.
  • Passing: Back leg passes under the body.
  • Up: Body reaches highest point before next contact.
  • Arms: Oppose the legs for balance.
  • Head/Torso: Add subtle bob or rotation.
  • Loop: First and last frame must connect cleanly.
  • Graph Editor: Smooth the cycle; remove mechanical pops.

Style Menu

Beginner Styling

  • Change stroke color
  • Change stroke width
  • Round vs. butt caps
  • Copy/paste style between hoses

Intermediate Styling

  • Multiple strokes for outlines
  • Trim Paths for sleeves/gloves
  • Tapered limb ends
  • Separate hands/feet parented to hose ends

Advanced Styling

  • Dashed or segmented limbs
  • Animated style reveals
  • Layer styles/effects
  • Saved custom style preset
⚠ Avoid This

Do not submit three versions of the same movement. A walk cycle, a wave, and a styled sleeve reveal are three different studies. A walk cycle, another walk cycle, and a slightly slower walk cycle are not.

Rubric

Technical Control - 35%

  • RubberHose rigs function cleanly
  • Hands/feet/props stay attached
  • Walk cycle loops without pops
  • Layers and controllers are organized

Animation Quality - 30%

  • Clear poses and readable silhouette
  • Intentional arcs, easing, and timing
  • Anticipation and follow-through
  • Different motion ideas across all three studies

Hose Styling - 25%

  • At least three styling methods used
  • Style supports the character design
  • No default unfinished hose look
  • Consistent visual system across limbs

Presentation - 10%

  • Clean render
  • Labels/title cards included
  • Correct file naming
  • Project collected and zipped
💡 Instructor Tip

Build one strong character system instead of three separate messy ones. Reusing the same character across all three studies is encouraged because it lets you focus on motion quality and styling consistency.
