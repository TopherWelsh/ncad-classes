Standard Operating Procedures

File Management & Folder Structure

In the professional world, organization is not optional. Motion Design projects often contain hundreds of files. If you lose one file, your entire render fails.

From this day forward, you are required to use this exact structure.

⚠ The "Missing Footage" Rule

After Effects does not save media inside the project file; it only links to it. If you move a file after importing, the link breaks. Always put your assets into these folders BEFORE importing into After Effects.

02 — Naming Structure

Stop naming files final_final_v2.mp4. Use the NCAD Motion Design Studio Standard.

NCAD Standard Naming Convention

[Class]_[Assignment]_[StudentName]_[FileName]_[YYYYMMDD]_v01

Breakdown

  • [Class]: IntroMD — Keeps coursework separate
  • [Assignment]: Week01 or KineticType — Groups by project
  • [StudentName]: DoeJohn — LastFirst (Essential for grading)
  • [FileName]: MainComp or Bumper — Describes the file
  • [YYYYMMDD]: 20260107 — Chronological history
  • _v01: _v02, _v03 — Version control. Never use the word "Final"

Example: IntroMD_Week02_DoeJohn_BouncingBall_20260114_v03.aep

03 — How to Submit (Zipping)

📦 Why You Must Zip

If you only send the .aep file, I cannot see your images or hear your audio. You must send the entire folder structure.

Step-by-Step

  • 1. Save your work and close After Effects.
  • 2. Go to the root folder (the one containing AE, Audio, Videos folders).
  • 3. Right-Click the folder > Send To > Compressed (zipped) folder.
  • 4. Name the zip file using the Standard Naming Convention.
  • 5. Upload that .zip file to Canvas or Google Drive.
