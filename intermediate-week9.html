VFX Shot Production

Continue tracking, compositing, polishing, and exporting your three VFX shots.

Discord Student Resources Drive Week 8 Lesson

The Goal

By the end of this project, you should have three finished VFX shots, each 5-10 seconds long, where a digital element is tracked and composited into real footage with intentional polish.

Production Targets

Shot 1: Clean Track

Pick the shot most likely to succeed. Focus on stable tracking, correct placement, and basic color/blur matching.

  • Good surface detail.
  • Simple camera move.
  • Clear attached object/text/artwork.

Shot 2: Interaction

Add a little more complexity. Use masking, foreground occlusion, shadow, reflection, or a more interesting camera move.

  • Object interacts with the space.
  • Some foreground/background relationship.
  • More attention to lighting.

Shot 3: Style / Ambition

Use your strongest idea. This can be a 3D model, stylized graphic, surreal object, UI layer, portal, logo, or environmental extension.

  • Strongest visual hook.
  • Most portfolio-friendly shot.
  • Extra polish pass required.

Work Session Order

Do This In Order

  • 1. Choose footage: Pick the three best clips, not the three coolest ideas.
  • 2. Track each shot: Run 3D Camera Tracker and create a camera/null/solid.
  • 3. Place the object: Attach text, artwork, or 3D layers to the tracked space.
  • 4. Rough export: Watch the shot outside After Effects before polishing.
  • 5. Composite pass: Match scale, color, blur, grain, and lighting.
  • 6. Masking pass: Add foreground occlusion if anything should pass in front.
  • 7. Sound/title optional: Add subtle sound or labels only if it helps the shot.
  • 8. Final export: Render all three shots and package your project files.
⚠️ Do Not Spend All Week on One Shot

This assignment is three shots. If one shot is fighting you for too long, simplify the effect, choose cleaner footage, or move on. Three finished shots beat one complicated unfinished shot.

Final Quality Checklist

Technical Checklist

  • The object does not slide or drift.
  • The perspective feels believable.
  • Scale matches the real environment.
  • Motion blur and grain are not too clean.
  • Render plays smoothly from start to finish.

Compositing Checklist

  • Lighting direction makes sense.
  • Color temperature matches the footage.
  • Shadows or contact points help ground the object.
  • Foreground masks are clean if used.
  • The shot has a clear visual idea, not just a technical demo.

Submission Requirements

Final Renders

  • 3 exported video files.
  • Each shot is 5-10 seconds.
  • Portrait or landscape is allowed.
  • Use clear file names for Shot 01, Shot 02, and Shot 03.

Project Archive

  • After Effects project file.
  • Original footage or linked footage location.
  • Imported artwork/models/assets.
  • Collected/zipped folder when possible.

NCAD Submission Standard

Intermediate_W9_StudentName_VFXShots_YYYYMMDD_v01

Deliverables: Upload 3 final video renders plus a collected/zipped project folder. Label each render clearly: Shot01, Shot02, Shot03.
