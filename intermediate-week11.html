Demonstrating UX Motion Principles in After Effects

This week turns the Week 10 principles into working motion studies. We will build small After Effects demos that show how each UX motion principle can be communicated through actual keyframes.

Discord Google Drive Week 10 Principles

Lab Goal

Use After Effects to demonstrate the 12 Principles of UX in Motion. Each demo should be simple, readable, and tied to a usability purpose: expectation, continuity, narrative, or relationship.

What We Are Building

A Principle Board

A single AE project with labeled mini-comps for each principle. Each comp should be small enough to understand quickly.

Short Motion Studies

Each motion study should demonstrate one UX motion principle in a few seconds. No full app prototype is required.

Usability Notes

Each demo needs a one-sentence rationale explaining what the motion clarifies for the user.

AE Technique Map

1. Easing

Use the Graph Editor to make a panel, button, or card feel responsive instead of robotic.

2. Offset & Delay

Stagger layers so the order of motion communicates hierarchy and sequence.

3. Parenting

Use nulls and parented layers so related objects move together or respond to each other.

4. Transformation

Animate one object changing function, such as a button becoming a progress bar or check mark.

5. Value Change

Animate numbers, labels, or progress values so the viewer understands what changed.

6. Masking

Use masks or track mattes to reveal content from a logical source or container.

7. Overlay

Use stacked layers, opacity, blur, and shadow to show foreground/background relationships.

8. Cloning

Duplicate or emit a new element from an existing object so its origin is clear.

9. Obscuration

Dim, blur, or partially cover the background to show a secondary layer of interface space.

10. Parallax

Move foreground, midground, and background layers at different speeds to establish hierarchy.

11. Dimensionality

Use 3D layers, rotations, folds, or cards to show origin, departure, and spatial logic.

12. Dolly & Zoom

Use scale, camera moves, or null-driven zooms to move between interface spaces while preserving context.

In-Class Build Sequence

Lab Flow

  • Set up the board: Create one main project with 12 labeled comps.
  • Start with timing: Build Easing and Offset & Delay first because they affect every other principle.
  • Add relationships: Build Parenting with a parent object, child object, and visible response.
  • Build continuity demos: Create Transformation, Value Change, Masking, Overlay, and Cloning studies.
  • Add hierarchy: Build Parallax with at least three visual depth layers.
  • Add spatial continuity: Build Obscuration, Dimensionality, and Dolly & Zoom studies.
  • Write labels: Add principle names and one-sentence usability notes.
  • Export a review pass: Render either individual MP4s or one combined principle board video.

Demo Requirements

Keep It Simple

  • Use basic shapes, type, and UI cards.
  • Do not overdesign the interface.
  • The motion principle should be the point of the demo.
  • Each example should read within a few seconds.

Make It Usable

  • Every demo should answer a user-facing question.
  • The trigger and result should be obvious.
  • Timing should support comprehension.
  • Labels should explain the principle without rescuing unclear motion.
